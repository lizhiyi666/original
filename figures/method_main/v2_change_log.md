# Method Main Figure V2 Change Log

## Scope

V2 revises the scientific organization of the method overview without changing any algorithm implementation or source-code behavior.

## Changes from V1

1. Split Panel (a) into explicit `TRAINING` and `INFERENCE / GENERATION` lanes.
2. Routed `po_matrix` as an independent constraint specification directly into the reverse-step projection point; it no longer appears as an output of condition representation.
3. Embedded the constraint operation inside the reverse diffusion loop between category-position logits and the next reverse state.
4. Added the shared callout `①` and a corresponding `① Detail` Panel (b) to establish the overview/detail relationship.
5. Separated `Category-position logits′` from `POI logits (unchanged)` and explicitly marked the category-position mask as sequence-position selection rather than candidate filtering.
6. Added boundary notes stating that no candidate filtering or explicit POI transition restriction is implemented, and that the constraint acts during reverse diffusion.
7. Kept the contribution chain visually emphasized with terracotta: `po_matrix → constraint parsing → order/existence energy → KL-preserving ALM projection → category-position logits′ → joint sampling`.
8. Repaired the Draw.io XML root structure so the editable source is well-formed.
